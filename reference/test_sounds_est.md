# Extended selection table with re-recorded playbacks

Extended selection table (est) of 7 re-recorded synthetic sounds. The
synthetic sounds are 2 s long, frequency modulated, amplitude modulated,
and were broadcast and re-recorded at 3 distances (1, 10, and 30 m,
column `distance`). The data was created by
[`warbleR::selection_table()`](https://marce10.github.io/warbleR/reference/selection_table.html)
from the **warbleR** package. The master sound file data used to create
these test sounds is found in the example object
[master_est](https://marce10.github.io/baRulho/reference/master_est.md).

## Usage

``` r
data(test_sounds_est)
```

## Format

Extended selection table object in the
[warbleR](https://cran.r-project.org/package=warbleR) format, which
contains annotations and acoustic data.
